# Support

Use the schema and examples in README.md first. In a bug report, include the extension version, editor version, expected result and a minimal invented CSV that reproduces the issue. Remove personal names, confidential notes and business measurements before sharing a sample.

Report editor defects through the [Sewlore measurement extensions issue tracker](https://github.com/gokimedia/sewlore-measurement-extensions/issues). Identify the editor extension and include a minimal invented reproduction. The [Sewlore measurement guide](https://sewlore.com/pages/fabric-measurement-methods-guide) documents the recording method; it is not a substitute for checking an editor defect.
