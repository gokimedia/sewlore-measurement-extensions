Privacy and data handling

Sewlore Measurement Check · version 0.1.0

The extension does not collect, transmit or sell personal data, browsing data or measurement entries. It contains no analytics, advertising, telemetry, account login or automatic network requests.

Values and optional record labels exist only in the open popup's memory. Closing the popup clears them. The extension does not store them in browser storage or cookies.

When you explicitly choose a CSV export, the extension asks your browser to download a local CSV file. You control that file and where it is saved. Spreadsheet-formula-like labels are prefixed with an apostrophe; quotes and line breaks are escaped.

The documentation link opens Sewlore's public website only if you click it. That visit is handled by your browser and the website's own privacy policy; calculation inputs and labels are never included in the link.

The extension requests no website access and no extension API permissions. It cannot read your tabs, page content, browsing history or cookies.
