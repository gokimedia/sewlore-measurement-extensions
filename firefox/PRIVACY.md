# Sewlore Measurement Check privacy statement

Version 0.1.0. Updated 9 October 2026.

The extension does not collect, transmit or sell personal data, browsing data or measurement entries. It contains no analytics, advertising, telemetry, login, automatic network requests, browser storage or cookies.

Inputs and optional record labels exist only in the open popup's memory. Closing the popup clears them. Clicking a CSV export downloads a local file controlled by the user. Labels that resemble spreadsheet formulas are prefixed with an apostrophe and standard CSV escaping is applied.

The optional documentation link opens the Sewlore website only when clicked. That visit is handled by the browser and the website's privacy policy. Inputs and labels are never appended to the link. The extension requests no website access or extension API permissions and does not read tabs, page content, browsing history or cookies.
